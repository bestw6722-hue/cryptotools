# CryptoTools

A real static crypto utility website foundation.

## Live price option
The site does not ship with an API key. The calculator architecture can use a CoinGecko Demo API key stored locally in the visitor's browser. See CoinGecko's official API documentation for current authentication and usage limits.

## Monetization
Do not add fake referral links. Join legitimate programs yourself, then replace CTA destinations with your approved referral URLs. Add advertising only after meeting the ad network's requirements.

## Before public launch
- Replace placeholder legal/contact pages.
- Add your real domain.
- Connect Search Console/analytics.
- Add verified affiliate links.
- Review local financial/advertising rules for every market you target.
